# A5-1 壓抑衝動：設計（定稿）

> 狀態：**定稿**（作者 2026-10-14）：玩法 OK；**改成連打空白鍵**（不是按住）；妻子失敗直接 Bad End；**女兒不做抵抗**（她會直接跑掉）；文字定稿：提示「連打【空白鍵】抵抗」、成功「你咬緊牙，那股衝動慢慢退去。」
> 示意圖：`art/design/a5/resist/mock_resist.png`（量表 35%／80%；對話框裡的句子是示意，不是實際文字）。

## 1. 為什麼要改流程

現在每個有衝動的事件（婦人、女科學家、警衛、妻子、女兒）打完字就直接出選項，「撲上去」只是其中一個選項，玩家想避開就避開，衝動沒有實際的壓力。
壓抑衝動讓**身體的本能先動**：玩家要先撐過衝動，才拿回選擇權。

## 2. 玩起來的樣子

1. 走近人物、事件文字打完後，**選項還不出現**，改成出現「按住【空白鍵】抵抗」和一條量表。
2. 紅色暈影、心跳、鏡頭晃動都在最強；主角前傾。
3. **按住空白鍵**量表會往上漲；**放開會往下掉**；每次心跳量表被「拉」掉一點（衝動在拉扯）。**量表一開始在一半**（2026-10-29 作者：一開始是空的看不出用途；`main.gd` 的 `RESIST_START`），按住的秒數、連打的次數不變（每次漲的是剩下那一半）；不按的話約 2 秒掉到空。
4. 結果：
   - **成功**（在時限內漲滿）：心跳慢下來、紅色退去，顯示一句「你咬緊牙，那股衝動慢慢退去。」，然後出現選項，**「撲上去」類的選項不見了**。
   - **失敗**（時限到了還沒滿）：**自動撲上去**，等於選了「撲上去」那個選項（畫面震動、低吼、顯示那個選項的回應文字、套用它的數值與去處）。

- 數值：抵抗本身**不加數值**，數值仍然來自選項（成功後選的、或失敗時的撲上去）。這樣不用重算結局平衡。
- Bad End 的「從這裡重試」回到進入區域時，會重新抵抗一次。

## 3. 每個事件的設定（難度）

| 事件 | 失敗時等於 | 結果 | 難度（要按住幾秒／時限） |
|---|---|---|---|
| 停車場：婦人 | 撲上去 | 人性 −1 | 1.5 秒／5 秒（第一次，教學性質） |
| 設施走廊：女科學家 | 撲向她 | 人性 −2，她逃走、拿不到筆記本 | 2.0／5 |
| 設施走廊：警衛 | 撲向警衛 | 人性 −1 | 2.0／5 |
| 避難所：妻子 | 撲向她 | **Bad End「噬語」** | 2.5／5 |
| 舊家：窗外的女兒 | 靠近她 | 人性 −1，她逃走 | 2.5／5 |

- 婦人抵抗成功後只剩「強行壓制自己」一個選項，照樣顯示讓玩家確認。
- 難度和每次心跳拉掉多少都放在資料或屬性面板，試玩後調整。
- **測試版改成按住**（作者 2026-10-16）：`main.gd` 的 `RESIST_HOLD = true`，依資料的 `hold` 秒數（婦人 1.5、女科學家 2.0、警衛 2.0、妻子 2.5），提示「按住【空白鍵】抵抗」（`story.json` 的 `resist_prompt_hold`）；**正式版改回連打**（`RESIST_HOLD = false`，用 `presses`）。成功後要放開空白鍵選項才出現。
- **實作改成連打**（作者 2026-10-14）：資料 `presses` 是要連打幾下。第一版婦人 10、女科學家 14、警衛 14、妻子 18；作者要求調低 → **婦人 6、女科學家 8、警衛 8、妻子 10**（時限都是 5 秒）。

## 4. 新文字（草稿，請作者定稿）

| 用途 | 文字 |
|---|---|
| 抵抗提示（量表上方） | 按住【空白鍵】抵抗 |
| 成功（顯示在事件文字後面，選項出現前） | 你咬緊牙，那股衝動慢慢退去。 |

> 失敗時沿用「撲上去」選項原本的回應文字，不用新寫。

## 5. 資料格式

```json
"woman": {
  "type": "choice", "trigger": "approach", "impulse": { "range": 420 }, ...,
  "resist": { "hold": 1.5, "time": 5.0, "fail": 1 }
}
```

- `resist.hold`：要按住幾秒；`time`：時限；`fail`：失敗時等於第幾個選項（從 0 開始），成功時這個選項會隱藏。
- 女兒的選項寫在 variants 裡，`resist` 一樣放在互動點上，`fail` 指向「靠近她」。
- 劇本檢查：`hold`、`time` 是正數、`hold < time`、`fail` 指向存在的選項。

## 6. 其他

- 設定畫面（A6）可以加「自動抵抗」開關，給不想玩按鍵的玩家。
